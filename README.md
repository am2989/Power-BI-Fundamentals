# Power-BI-Fundamentals
Power BI Fundamentals: From Data Transformation to Dashboard Design
Fontes: Notas retiradas do Curso Santander Academy "Fundamentos de Power BI"
Este guia de estudo estruturado aborda os fundamentos do Power BI, detalhando desde a importação de dados até à criação de relatórios visuais avançados. O texto explica como utilizar o Power Query para transformar e limpar informação, destacando a importância de estabelecer um modelo de dados relacional eficaz. São apresentadas instruções práticas para configurar tabelas, matrizes e gráficos, além de ensinar a aplicação de filtros e formatação condicional para otimizar a análise. O conteúdo foca-se na transição entre as ferramentas de inteligência de negócio do Excel e este ecossistema moderno, permitindo uma tomada de decisão baseada em dados atualizados. No final, o documento consolida o conhecimento através de exercícios práticos e tabelas de consulta rápida sobre os principais comandos da aplicação.
